# Temporal VFX v0.11

## Question

Can Creative Render carry a real Visual Effect Fabric Hand graph across a short rendered sequence, composite each effect through Universal Creation's public Creative Flow, and preserve the exact resulting frames into verified FrameState video evidence?

## Executable path

`Universal Creation rig/clip -> sparse scene samples -> Render Fabric + receipt replay -> exact PPM frames -> per-frame Visual Effect Fabric electric Hand graph -> canonical effect state -> bounded Creative Render path raster -> Universal Creation screen composite/contrast -> exact composite PPMs -> FrameState project -> verified video evidence`

The v0.11 proof deliberately uses sparse effect samples. Each frame receives an explicit deterministic seed. Effect state, derived SVG, bounded effect raster, UC composite flow and final PPM remain separately hash-bound.

## Authority boundaries

- Universal Creation owns its public creative Hands and Creative Flow receipts.
- Visual Effect Fabric owns the electric Hand graph and its canonical effect state.
- Render Fabric owns the source rendering and renderer receipts.
- Creative Render performs explicit bounded adaptation and evidence binding; it does not promote its path raster into VFX source truth.
- FrameState is used as an evidence-admitted temporal/video body; it does not gain authority over upstream creative state.

## Four-root gate

- **Truth:** effect state, raster adaptation, frame composition and video assembly remain separate claims with explicit hashes.
- **Agency / non-domination:** seed policy, donor revisions and operations are explicit; no hidden renderer/effect substitution is allowed.
- **Continuity:** the exact temporal VFX composite hashes must become the exact FrameState project source hashes before final video evidence passes.
- **Wisdom before speed:** sparse per-frame VFX is proven before continuous effect simulation, renderer-native passes or game-world insertion.

## Truth boundary

This does **not** claim native Render Fabric VFX passes, physical light interaction, continuous-time effect simulation between sparse samples, complete realization of all Visual Effect Fabric semantics, artistic/cinematic quality, game-world runtime insertion, or cross-machine bitwise MP4 identity.
