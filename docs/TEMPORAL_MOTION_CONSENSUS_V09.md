# Multi-Region Temporal Motion Consensus v0.9

v0.8 proved that one deterministic evidence-rich image region can be measured by Universal Creation's translation block matcher, drive translation stabilization, reduce the exercised region's error, and survive into a verified video body. v0.9 asks a narrower and stronger question: can several spatial regions independently recover a **known image-space translation** generated through Universal Creation, while preserving every regional receipt and refusing to pretend that rotating/deforming scene motion is one global translation?

## Executable path

1. Universal Creation rig/clip state is sampled at `0`, `0.25`, `0.5` and independently rendered/receipt-verified by Render Fabric. Those original scene-motion frames remain evidence and are not silently rewritten.
2. The exact verified Render Fabric frame at `t=0` becomes the source of a controlled translation sequence.
3. Universal Creation Creative Flow invokes the real `creative.frame-finish.overlay-at` Hand over an explicit black same-size raster to create known image-space control offsets `0,0`, `4,2`, `8,5`. The control generation executes twice and must repeat to identical output PPM bytes.
4. Creative Render scans the exact control reference PPM and deterministically chooses three spatially diverse local RGB edge-energy regions.
5. Each selected region independently invokes the unchanged Universal Creation `creative.frame-finish.block-match-track` Hand against each translated control frame.
6. Creative Render computes component-wise integer median `dx/dy` as consensus evidence only. The proof requires those medians to recover the exact known control offsets.
7. A regional track is an inlier only when both axis deviations from that median stay within the explicit `maxAxisSpread` policy. Three regions require at least two inliers; five regions require at least three.
8. If fewer than that strict-majority quorum remain, the lane fails closed. Disagreeing regional track receipts remain visible as outliers.
9. Creative Render selects the **actual inlier Universal Creation track receipt** nearest the median, breaking ties by lower tracker MSE and stable region index. It does not manufacture or relabel a synthetic consensus receipt.
10. That real receipt returns to Universal Creation Creative Flow for `stabilize-translation`, followed by `difference-frame` and aligned `motion-trail` finishing.
11. The track/post path executes twice. Regional tracks, classification, representative choice, stabilized frames, residual frames and final PPM bytes must repeat exactly.
12. The exact final PPM hashes become the exact FrameState project source hashes before deterministic repeat verification, read-only evidence admission and explicit FFmpeg MP4 assembly.

## Failed runs kept as evidence

The first v0.9 consensus attempt used the rotating/animated rig frames themselves and required all selected patches to agree under a single translation model. It reached the new lane after **39/39 Creative Render tests**, three distinct Universal Creation temporal samples, **33/33 Render Fabric tests**, and three verified renderer outputs, then failed before FrameState/video assembly:

`multi-region track disagreement at frame 2: spread dx=0, dy=11`

That correctly exposed that a rotating projected cube does not guarantee one shared local vertical translation across independent patches.

A second repair replaced unanimity with strict-majority median inliers while preserving outliers. That still failed on the same rotating/deforming proof body because only one of the three selected regions stayed within the bounded global-translation consensus on the problematic frame. This is not evidence that the block matcher is broken; it is evidence that the proof scene violates the stronger single-global-translation assumption.

The current repair therefore does **not** widen the disagreement threshold, cherry-pick a convenient rig patch, or erase the negative result. Instead it separates two questions:

- the original rig clip remains negative evidence showing that local motion under rotation/deformation is not safely reducible to one global translation by this gate;
- the positive v0.9 executable proof uses a known image-space translation control generated by Universal Creation itself, then requires multi-region tracking to recover those exact offsets before video admission.

This turns the gate into a falsifiable calibration test rather than forcing an unsuitable scene to pass.

## Bounds

- translation-control sequence: 2..8 frames, first offset exactly `0,0`, distinct integer offsets in `-64..64`;
- consensus sequence: 2..12 frames;
- 3 or 5 tracking regions only;
- equal P6 RGB8 dimensions;
- at most 32 MiB decoded RGBA bridge state;
- local-region overlap limited to 25% of the smaller region area during automatic selection;
- each Universal Creation block-match call remains under its native 32,000,000 pixel-test work bound;
- total modeled regional tracking work capped at 64,000,000 pixel tests per bridge invocation;
- search radius `0..64`;
- per-axis median-deviation threshold `0..32` pixels, proof default `4`;
- strict-majority quorum: 2/3 or 3/5;
- inlier/outlier indices, raw regional spread, inlier spread and representative receipt identity remain explicit;
- trail window `1..8`, decay `0..1`;
- translation-only stabilization.

## Authority boundary

Universal Creation remains executor/authority for control-frame translation, each regional track, stabilization, difference and trail Hand. Creative Render owns adapter logic, deterministic region selection, consensus evidence, fail-closed policy and selection among already-existing real inlier UC receipts. The median is never represented as a UC-generated receipt. Render Fabric remains renderer authority. FrameState remains `EVIDENCE_ADMISSION_ONLY`. FFmpeg remains an explicit external assembly boundary.

## Truth boundary

This gate proves recovery of known bounded image-space translations, not general scene motion. It does not prove optical flow, semantic object tracking, camera motion under parallax, independent-object separation, rotation/scale/perspective stabilization, continuous-time interpolation, cinematic quality or universal correctness. The earlier rotating-rig failures are deliberately preserved because they define where the translation-consensus model stops being valid.
